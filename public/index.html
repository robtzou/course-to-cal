Technical Documentation

Course to Calendar

An automated scheduling utility converting unstructured image data into structured calendar events via multimodal AI analysis.

v1.2.0 Powered by Gemini

End-User Workflow

1

Capture Schedule

Take a screenshot of your weekly course grid from your university portal (Canvas, Blackboard, etc.). Ensure column headers (Days) and row headers (Times) are visible.

2

Upload Image

Drag & drop the image file (.png, .jpg) into the application dashboard. The system will auto-validate the file type.

3

Verify Parsing

A preview list appears. Review the class times and locations. Use the icon to correct any misread text before finalizing.

4

One-Click Sync

Click "Sync to Google Calendar". The app requests OAuth permission and populates your calendar for the entire semester.

Troubleshooting Tip

If a class is missing, your screenshot might be cropped too tightly. Ensure the "Day of Week" headers are clearly visible in the image.

AI Integration Architecture

1. Input Processing

The image is base64 encoded and passed to the backend. We utilize Google Gemini 1.5 Flash via the Vertex AI API for its high-speed multimodal capabilities.

POST /v1/models/gemini-1.5-flash:generateContent
{ "inlineData": { "mimeType": "image/png", "data": "..." } }

2. Prompt Engineering Strategy

We use a Structured Output prompt strategy. The system instruction strictly enforces a JSON schema, ensuring the LLM does not return conversational text.

  • Role: "You are a data extraction engine."
  • Task: Extract Course Code, Location, Start Time, End Time, Days (Mon-Fri).
  • Constraint: "Infer duration from grid height if time is not explicit."

3. Data Normalization

Raw JSON from Gemini is parsed. Logic is applied to convert natural language days (e.g., "T/Th") into RRULE format for calendars.

"Tuesdays" BYDAY=TU

4. Privacy Guardrails

Zero-Retention Policy: The image buffer is cleared from memory immediately after the API response is received. No user schedules are stored in a database.
